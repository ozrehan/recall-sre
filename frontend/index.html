How Hindsight powers this

Every resolved incident — error signature, symptoms, root cause, investigation steps, commands, fix, and MTTR — is stored as a memory in Hindsight. When a new incident fires, the agent searches that memory for similar past incidents and recommends investigation steps drawn from what actually worked before. Similar symptoms can have different causes, so every recommendation is framed as an evidence-backed hypothesis, never a certainty.

Run your own

python backend/server.py — set HINDSIGHT_API_KEY to use Hindsight Cloud (URL defaults to https://api.hindsight.vectorize.io), or set HINDSIGHT_URL for a self-hosted instance (no key needed if auth is off). Optionally set GROQ_API_KEY for LLM-synthesized briefings. Without keys, the demo runs on an identical local memory interface.
