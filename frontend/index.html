🧬 Organizational memory

How Hindsight powers this: every resolved incident — error signature, symptoms, root cause, investigation steps, commands, fix, MTTR — is stored as a memory in Hindsight. When a new incident fires, the agent searches that memory for similar past incidents and recommends investigation steps drawn from what actually worked before. Each resolution makes the next incident faster. Set HINDSIGHT_URL + HINDSIGHT_API_KEY to use a real Hindsight backend; otherwise the demo runs on a local similarity store with the identical interface.
